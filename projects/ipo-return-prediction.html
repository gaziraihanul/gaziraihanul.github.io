IPO Return Prediction

Machine Learning • Financial Analytics • Research

Overview

This project investigates whether long-term IPO performance is driven more by investor hype or by company fundamentals. Using a dataset of 3,158 U.S. IPOs between 2009 and 2023, I developed machine learning models to predict IPO returns across multiple investment horizons and compare the predictive power of behavioural and fundamental signals.

Research Question

Do short-term market reactions provide greater predictive value than pre-IPO company fundamentals when forecasting long-run stock performance?

Dataset

  • 3,158 U.S. IPOs (2009-2023)
  • LSEG / Refinitiv IPO data
  • SEC EDGAR S-1 filings
  • FRED VIX data
  • S&P 500 benchmark data

Technical Stack

Python Pandas NumPy Scikit-Learn Random Forest XGBoost SHAP Machine Learning Financial Analytics

Key Findings

IPO Underperformance Confirmed

The median IPO underperformed the S&P 500 by approximately 12 percentage points over its first year after listing.

Random Forest Performed Best

Random Forest consistently outperformed other models and achieved roughly 0.38 out-of-sample R² for one-year return prediction.

Log Proceeds Was the Strongest Predictor

Deal size emerged as the most consistently important feature across multiple time horizons.

Hype Beat Fundamentals

Contrary to the original hypothesis, short-term market signals provided more predictive power than pre-IPO fundamentals when forecasting long-run IPO returns.

What This Project Demonstrates

This project combines data cleaning, feature engineering, machine learning, explainable AI, financial modelling, cross-validation, and statistical research into a complete end-to-end analytics workflow.
